# KET 名词闪卡（打印贴纸）

从工程 KET 词库（A1/A2 具体名词）筛出的 **246** 张纯图像闪卡，用于实物贴纸效果预览。

## 规格

- 纸张：A4，300 DPI
- 卡片：约 4.95 × 4.95 cm 正方形（不超过 9 × 5 cm）
- 排版：每页最多 24 张（4 × 6），贴边满版，浅灰裁切线
- 内容：仅图像，无文字；白底

## 文件

| 文件 | 说明 |
| --- | --- |
| `ket-flashcards-a4.pdf` | 完整 11 页打印稿（主文件，300 DPI） |
| `ket-flashcards-a4-p01.png` … `p11.png` | 单页预览（已压缩，每张 &lt; 500KB） |
| `cards/*.png` | 单张原图（按词名命名，每张 &lt; 500KB） |
| `ket-flashcards-index.txt` | 每页词表索引 |

打印时请选 **实际大小 / 100%**，不要“适应页面”。若打印机不支持无边距打印，贴边几毫米可能被裁掉。

## 覆盖范围

食物饮品、动物、交通、家居物品、衣物、身体部位、自然天气、学校日常、运动、场所建筑等可一眼识别的具体名词；抽象词与关系词未收录。
