# 背它一辈子 - 小程序简介（简短版）

## 应用简介

**背它一辈子**是一款专业的英语单词学习小程序，采用科学的间隔重复算法，帮助您高效记忆单词，实现长期记忆。

## 核心功能

### 📚 智能学习
- **卡片翻转学习**：双面卡片设计，点击即可查看详细内容
- **间隔重复算法**：基于 SM-2 算法，科学安排复习时间
- **多级别支持**：A1/A2（基础）、B1/B2（中高级）、C1/C2（高级）

### 🎯 个性化设置
- **每日复习数量**：灵活设置 10/50/200 或自定义
- **级别选择**：根据英语水平选择合适的级别

### 📊 学习统计
- **数据可视化**：总学习数、已掌握数、学习天数
- **学习热力图**：日历形式展示学习活跃度

### 🗣️ 语音学习
- **标准发音**：支持美式和英式发音
- **一键播放**：点击即可听到标准发音

### ⭐ 评分系统
- **5 级评分**：根据记忆效果进行评分
- **智能调整**：系统根据评分调整学习节奏

### 💬 用户反馈
- **快速反馈**：简洁的表单设计，快速提交反馈

## 适用人群

- **学生**：考试备考（四六级、雅思、托福等）
- **上班族**：提升职场英语能力
- **英语爱好者**：满足英语学习兴趣

## 快速开始

1. 打开小程序，使用微信账号登录
2. 选择适合的级别和每日复习数量
3. 开始学习，系统自动记录进度
4. 查看统计，了解学习成果
