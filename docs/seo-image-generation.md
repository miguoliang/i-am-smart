# SEO Image Generation Guide

This guide explains how to generate the required SEO images from `pwa-icon-108.png`.

## Source Image

All PNG icons are generated by scaling **`public/pwa-icon-108.png`** to the required sizes.

## Required Images

1. **og-image.png** (1200x630px) - Open Graph image for social media sharing
2. **logo.png** (512x512px) - Logo for structured data
3. **favicon.png** (32x32px) - Browser favicon
4. **icon.png** (512x512px) - App icon
5. **apple-icon.png** (180x180px) - Apple touch icon
6. **icon-192.png** (192x192px) - PWA icon
7. **icon-512.png** (512x512px) - PWA icon

## Prerequisites

Install sharp (image processing library):
```bash
npm install sharp
```

## Generation Steps

### 1. Generate All Icons
```bash
node scripts/generate-icons.mjs
```

This will create all icon sizes from `pwa-icon-108.png`:
- `public/favicon.png` (32x32)
- `public/icon.png` (512x512)
- `public/apple-icon.png` (180x180)
- `public/icon-192.png` (192x192)
- `public/icon-512.png` (512x512)

### 2. Generate Logo
```bash
node scripts/generate-logo.mjs
```

This will create `public/logo.png` (512x512) from `pwa-icon-108.png`.

### 3. Generate OG Image
```bash
node scripts/generate-og-image.mjs
```

This will create `public/og-image.png` (1200x630) with `pwa-icon-108.png` centered on an amber background.

### 4. Generate Favicon.ico (Optional)

For favicon.ico, convert `favicon.png` to ICO format:

**Option A: Use online converter**
1. Use online tool: https://convertio.co/png-ico/ or https://favicon.io/favicon-converter/
2. Upload `public/favicon.png` and download `favicon.ico`

**Option B: Use to-ico CLI**
```bash
npm install -g to-ico
to-ico public/favicon.png -o public/favicon.ico
```

## Alternative: Manual Creation

If you prefer to create images manually:

1. **OG Image** (1200x630px):
   - Use design tool (Figma, Canva, Photoshop)
   - Include: Site name, tagline, key features
   - Save as PNG

2. **Logo** (512x512px):
   - Square format
   - High resolution
   - Transparent background preferred

3. **Favicon** (32x32px):
   - Simple, recognizable icon
   - Works at small sizes
   - ICO format for best browser support

## Verification

After generating images, verify they exist:
```bash
ls -lh public/og-image.png public/logo.png public/favicon.* public/icon.png public/apple-icon.png
```

## Notes

- SVG sources are provided for easy customization
- All images should be optimized for web (use tools like ImageOptim or Squoosh)
- Consider creating @2x versions for retina displays if needed
- Test OG image with: https://www.opengraph.xyz/ or https://developers.facebook.com/tools/debug/
