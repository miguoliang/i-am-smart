## 1. UI & Styling (Settings Drawer)

### 1.1 Component Implementation (`TopBar.tsx`)
- **Strengths:**
  - **Mobile-First**: Correctly uses `env(safe-area-inset-top)` for mobile viewport safety.
  - **State Management**: Clean use of local state for drawer visibility.
  - **Composition**: Settings content is well-structured with clear sections (Level List, Actions).
  - **Accessibility**: Uses `sr-only` for icon-only buttons ("关闭").
- **Areas for Improvement (Accessibility & Consistency):**
  - **Custom Drawer Implementation**: The drawer is implemented manually using fixed positioning and CSS transforms.
    - *Risk*: Manual implementations often miss complex accessibility features like **Focus Trapping** (keeping tab focus inside the drawer while open) and **Scroll Locking** (preventing background body scroll).
    - *Recommendation*: Refactor to use the standard `Sheet` component (from `components/ui/sheet`) if available in the project (Shadcn UI). This ensures consistent behavior and automatic WCAG compliance (ARIA attributes, focus management).
  - **Backdrop**: The overlay click handler is present, but ensure `Escape` key listeners are added if keeping the custom implementation.

### 1.2 UX Improvements
- **Level Selection**: Clear visual feedback (checkmarks) for the selected level.
- **Push Notifications**: Integrated toggle with loading states and optimistic UI feedback.
