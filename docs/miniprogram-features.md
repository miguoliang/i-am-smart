# 背它一辈子 - 小程序功能介绍

## 📱 应用简介

**背它一辈子**是一款专业的英语单词学习小程序，采用科学的间隔重复算法（SM-2），帮助您高效记忆单词，实现长期记忆。无论您是学生、上班族还是英语爱好者，都能在这里找到适合自己的学习方式。

## ✨ 核心功能

### 1. 📚 智能学习系统

#### 卡片翻转学习
- **双面卡片设计**：正面显示单词，背面显示释义和例句
- **点击翻转**：轻松点击卡片即可查看详细内容
- **进度追踪**：实时显示当前学习进度（如：3/10）

#### 间隔重复算法
- **科学记忆**：基于 SM-2 算法，根据记忆效果自动安排复习时间
- **智能复习**：系统会根据您的掌握程度，在最佳时间提醒复习
- **长期记忆**：通过科学的复习间隔，帮助您将单词牢牢记住

#### 多级别支持
- **A1/A2 级别**：基础词汇，适合初学者
- **B1/B2 级别**：中高级词汇（Pro 功能）
- **C1/C2 级别**：高级词汇（敬请期待）

### 2. 🎯 个性化设置

#### 每日复习数量
- **灵活设置**：支持 10、50、200 三种预设选项
- **自定义调整**：根据您的学习计划，灵活调整每日复习量
- **合理规划**：帮助您制定可持续的学习计划

#### 级别选择
- **自由切换**：根据您的英语水平选择合适的级别
- **循序渐进**：从基础到高级，逐步提升词汇量

### 3. 📊 学习统计

#### 数据可视化
- **总学习数**：记录您已学习的单词总数
- **已掌握数**：显示您已熟练掌握的单词数量
- **学习天数**：统计您的连续学习天数
- **学习热力图**：以日历形式展示您的学习活跃度

#### 进度追踪
- **实时更新**：每次学习后自动更新统计数据
- **历史记录**：查看您的学习历史轨迹
- **成就激励**：通过数据可视化激励持续学习

### 4. 🗣️ 语音学习

#### 发音支持
- **美式发音**：标准美式英语发音
- **英式发音**：标准英式英语发音
- **一键播放**：点击播放按钮即可听到标准发音
- **辅助记忆**：通过听觉记忆加深印象

### 5. ⭐ 评分系统

#### 记忆反馈
- **5 级评分**：根据记忆效果进行 0-5 分评分
- **智能调整**：评分影响下次复习时间
- **个性化算法**：系统根据您的评分调整学习节奏

### 6. 💬 用户反馈

#### 反馈收集
- **多维度反馈**：收集职业、学习目的、使用体验等信息
- **持续改进**：您的反馈帮助我们不断优化产品
- **快速提交**：简洁的表单设计，快速完成反馈
