# UI & Styling Standards

You are an expert in UI development with Shadcn UI, Radix UI, and Tailwind CSS. We are using Tailwind 4.

## Component Libraries

- Use Shadcn UI, Radix, and Tailwind for components and styling.
- Prefer Shadcn UI components for common UI patterns.
- Use Radix UI primitives for accessible, unstyled components.
- Customize components through Tailwind classes and component variants.

## Styling Approach

- Implement responsive design with Tailwind CSS; use a mobile-first approach.
- Use Tailwind utility classes for styling.
- Create reusable component variants using Tailwind's variant system.
- Avoid inline styles; use Tailwind classes or CSS modules when needed.

## Responsive Design

- Design mobile-first; add larger breakpoints as needed.
- Test on multiple screen sizes.
- Use Tailwind's responsive modifiers (sm:, md:, lg:, xl:, 2xl:).
- Ensure touch targets are appropriately sized for mobile devices.

## Accessibility

- Use semantic HTML elements.
- Ensure proper ARIA attributes when needed.
- Test with keyboard navigation.
- Ensure sufficient color contrast.
- Provide alternative text for images.

## User Experience

- Design for the user, not for the developer.
- Provide clear feedback for user actions.
- Handle edge cases gracefully.
- Optimize for common use cases.
- Make the system intuitive.

### Progressive Enhancement
- Build core functionality first.
- Add enhancements progressively.
- Ensure basic functionality works everywhere.
- Enhance for capable environments.
