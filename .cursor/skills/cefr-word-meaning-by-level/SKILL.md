# CEFR 词义按等级说明

## 何时启用

用户要求**按 A1–C2 说明同一单词在各等级需掌握的含义是否不同、如何递进**时使用。可与词条编辑（`cefr-vocab-json-translation`）配合：先理清等级差异，再写入 `chineseTranslation` / 例句。

## 核心原则

1. **含义 vs 能力**：许多词**核心义项不变**；差异主要在**可用语境、搭配、语体、比喻/引申、精确度**。先判断是否「多义递进」还是「同一义、用法变宽」。
2. **证据优先**：若仓库中有该词在 `cefr-a1.json` … `cefr-c2.json` 的条目，**先对照各文件中的 `level`、`chineseTranslation`、`exampleSentence`**，再概括；无数据则按通用 CEFR 与词典学常识推断，并标明推断。
3. **诚实标注**：若某等级通常**不要求**单独义项，写「该 band 一般不单独考核此义」或「与上一级相同，侧重……」。

## CEFR 与「掌握的含义」大致对应

| 倾向 | A1–A2 | B1–B2 | C1–C2 |
|------|--------|--------|--------|
| 义项数量 | 最常见 1 义；具体、日常 | 常见多义开始分化；抽象用法增多 | 低频义、比喻、语域限制、学术/专业义 |
| 精确度 | 能识别、复述基本义即可 | 能选对义项、基本搭配正确 | 细微差别、褒贬、正式度、固定搭配与类联接 |
| 产出 | 识别为主，简单复述 | 句子中正确使用 | 自然、得体、含语体意识 |

（以上为教学上的概括，非官方逐词表。）

## 工作步骤

1. **定词形与词性**：lemma、主要词性；是否多词性（名/动等）。
2. **列义项**：用简明中文或英文列出该词的主要义项（词典顺序或频率顺序）。
3. **逐带（A1→C2）标注**：
   - **须掌握的含义**：该等级学习者应能**理解或产出**的义；
   - **与下一带差异**：新增义、语体变窄/变宽、搭配要求、是否仅为「熟练度」提升。
4. **总结**：一句说明「主要是义项增加」还是「义项稳定、语域与搭配加深」。

## 输出模板（给用户）

使用下列结构，保持简洁；无差异的等级可合并写「与 B1 同义，要求更高流利度与搭配自然度」。

```markdown
## [单词]（[主要词性]）

### 总览
- 核心义是否在全程稳定：[是/否]；若有层级，一句话概括。

### 按等级
- **A1**：…
- **A2**：…
- **B1**：…
- **B2**：…
- **C1**：…
- **C2**：…

### 易混点（可选）
- 与近义词或同形异义的区分提示。
```

## 示例（说明写法，非唯一答案）

**Word：*bank***

- **A1–A2**：名词「河岸」与「银行」常分场景引入，通常先接触其中更课标化的一义。
- **B1**：两常见名词义并存；动词「存款 / 依赖（bank on）」多在 B 段出现。
- **B2–C1**：搭配扩展（blood bank, bank on）；语篇中根据上下文快速切换义项。
- **C2**：语体与专业语境中的固定用法、隐喻扩展（若教学大纲要求）。

**Word：*get*（动词）**

- **总览**：义项极多，低等级先掌握「得到、到达、变成」等少数高频结构；高等级覆盖更多短语动词与口语省略式，**语义网络变宽而非单一义替换**。

## 与项目数据

- 词汇文件路径：`apps/pwa/data/cefr-*.json`。
- 同一 `englishWord` 若出现在多个文件，以各条 `level` 与译文对照说明**等级间是否已拆义**。
- 编辑 JSON 时字段规则仍以 `cefr-vocab-json-translation` 为准。

## 避免

- 不要把每个等级都硬编一条「新义」；无新义时明确写**熟练度与语境**差异。
- 不要与欧洲理事会官方「can-do」描述逐字绑定到单个词（除非用户要求对照 can-do）。
